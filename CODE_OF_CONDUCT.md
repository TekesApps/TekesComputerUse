# Code of Conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its Code of Conduct, by reference. All participants in issues, pull requests,
discussions, and other project spaces are expected to follow it.

## Enforcement

Instances of unacceptable behavior may be reported to the TekesApps maintainers
through GitHub: use
[private vulnerability reporting](https://github.com/TekesApps/TekesComputerUse/security/advisories/new)
or contact a maintainer of the TekesApps organization directly on GitHub. All
reports will be reviewed and handled promptly and fairly, and the maintainers
will respect the privacy and security of the reporter.

Enforcement follows the
[Contributor Covenant 2.1 enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
