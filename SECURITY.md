# Security

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub private vulnerability reporting:
<https://github.com/TekesApps/TekesComputerUse/security/advisories/new>.

Do not open a public issue for a finding that could enable unauthorized screen
capture, accessibility control, input injection, or signature bypass.

## Notes for users

The helper cannot grant macOS privacy permissions. Release consumers must verify the published
SHA-256 digest and the helper's stable Apple code-signing identity before installation or upgrade.
